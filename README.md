# AI for Family Life: A Beginner's Manual

A plain-English, step-by-step guide to using free AI models for everyday family life — school forms, meal ideas, activities, and bedtime stories — without ever pasting your kids' names or school information into an AI chat.

## Who this is for

Parents, grandparents, and caregivers who want practical help with everyday family admin and who want to keep it private. No technical background needed. Everything here assumes nothing about what you already know.

## What's inside

| Folder | What's in it |
|--------|--------------|
| `docs/` | The full beginner manual in Markdown — printable and easy to read |
| `site/` | The same manual as a static HTML website you can open in any browser |
| `scripts/` | `verify.sh` — checks the site and docs are complete and correct |

### Manual sections

- **Getting started** — pick a free AI model, start your first chat, write a good prompt
- **Privacy & safety** — the never-paste rule and how to use placeholders instead
- **School forms** — understand forms, draft answers, track deadlines
- **Meal ideas** — plan dinners from what's already in your pantry
- **Activities** — rainy-day games, weekend outings, low-energy afternoons
- **Bedtime stories** — make up stories with AI, personalize them safely
- **Printable planners** — ready-to-print pages for meals, forms, activities, and stories

## Quick start

1. Read [`docs/privacy-safety.md`](docs/privacy-safety.md) first — the never-paste rule matters more than anything else.
2. Pick one section that would help you this week. School forms are a good place to start if you have paperwork piling up.
3. Follow one step-by-step example, then try it yourself with a real (but anonymized) task.
4. Print a planner from [`docs/printable-planners.md`](docs/printable-planners.md) or [`site/printable-planners.html`](site/printable-planners.html) and keep it on the fridge.

## How to run it

This is a static site — no build step, no server, nothing to install.

- Read the manual: open any file in `docs/` in a text editor or Markdown reader.
- Browse the site: open `site/index.html` in any web browser.
- Print planners: open `site/printable-planners.html` and press `Ctrl+P` (`Cmd+P` on Mac).
- Run verification: `bash scripts/verify.sh` (requires Python 3).

No network is required except to download an optional AI model (for example, [Ollama](https://ollama.com)) or visit linked external resources.

## Privacy promise (read first)

See [`docs/privacy-safety.md`](docs/privacy-safety.md). The short version:

**Never paste your kids' names, your school's name, addresses, phone numbers, email addresses, birthdays, or any other identifying family details into an AI chat.** Use placeholders like `[Child's name]` and `[School name]` instead, and fill in real details yourself on paper or in your own documents.
